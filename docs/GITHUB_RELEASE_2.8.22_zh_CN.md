# QCloudy_Addition Alpha 2.8.22（Minecraft 26.1.2 / 26.2）

Alpha 2.8.22 为每一次可选提供方能力扫描加入明确的第二次确认。

## 更新内容

- 首次开启“统一设置编辑”或“统一 HUD 编辑”且没有有效会话快照时，会先显示对应范围的确认窗口；确认前不会改变总开关，也不会开始扫描。
- 每一次 Refresh 都会进入同一确认流程。取消会保留当前已经校验的快照，且不执行扫描。
- Minecraft 重启后，即使总开关仍保持开启，也不会创建静默启动扫描。
- 窗口会说明提供方元数据只在本地读取，并可能短暂增加 CPU 占用；不会请求服务器或执行自动输入。
- 已有扫描运行时 Refresh 不可点击。

## 对应文件

- `QCloudy_Addition-Alpha-2.8.22+26.1.2.jar`
- `QCloudy_Addition-Alpha-2.8.22+26.2.jar`

请安装与 Minecraft 版本完全匹配的文件。Fabric API 仍为必需依赖；Mod Menu 与所有受支持 SkyBlock 提供方仍为可选项。

## 安全边界

提供方扫描仍为确定性、本地、只读过程。本次更新没有加入 HTTP、服务器查询、数据包、聊天、命令、遥测、自动输入或直接编辑提供方配置文件。

这是 Alpha 构建。双版本自动验证记录在 `docs/VALIDATION_zh_CN.md`；登录实服行为、每个提供方版本、每个材质包与每套完整模组组合仍需要游戏内测试。
