# QCloudy_Addition Alpha 2.8.19（Minecraft 26.1.2 / 26.2）

Alpha 2.8.19 是一次完整性、兼容性和性能维护更新。在保留 Alpha 2.8.18 全部功能的同时，删除已经确认的重复状态，并减少高频渲染和 tick 路径中的重复工作。

## 改进

- 兼容性缺失报告现在每次打开只进行一次提供方分组，并把换行后的行布局缓存到内容宽度改变，不再每帧重建相同布局。
- Lasso `REEL` 检测每次有效检查只遍历一遍已加载实体；本地玩家没有套索目标时，不再解析 ArmorStand 名称。
- Shard Fusion 索引不再保留一份从未读取的“全部配方”重复引用列表；精确输入、产物与用途查询继续共享同一组不可变配方对象和结果。
- Gradle 资源流程在配置阶段固定 Fabric Loader 元数据，消除了项目脚本对 Gradle 10 不兼容的执行期 API 弃用警告。
- 可运行 JAR 与 Sources JAR 都明确排除 Finder `.DS_Store` 元数据。

## 兼容性与安全边界

- 功能默认值、Shard 配方结果、提供方保存路径、HUD 含义、命令内容和网络行为均未改变。
- QCA 仍是可独立运行的纯客户端 Fabric 模组；本次更新没有新增数据包、自动点击、命令、聊天、HTTP、遥测、移动或玩法自动化。
- Minecraft 26.1.2 与 26.2 分别提供可运行 JAR 和 Sources JAR，请使用与游戏版本完全对应的文件。

不要把 `-sources.jar` 当作可运行模组安装。准确测试结果与 SHA-256 记录在 `docs/VALIDATION_zh_CN.md`。
