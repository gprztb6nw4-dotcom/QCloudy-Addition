# Alpha 1.5.3 — 相比 1.5.1 的变化

QCloudy_Addition Alpha 1.5.3 重新整理了设置界面，改进狩猎与 Safari HUD，修复多个解析和空面板问题，并删除三个不再维护的物品栏相关功能。

## 主要变化

- 设置界面重组为七个清晰的一级分类，并加入可收起/展开的二级功能组。
- 加入独立的 Galatea/Hina Chapter 与 Agatha's Contest 追踪。
- 加入可选的 Safari 捕获 Shard 统计；默认关闭，按地区分类，并按照品质上色。
- HUD 没有实际内容时会完全隐藏，不再残留空面板。
- Critter Safari 中不再显示宠物 HUD。
- 修复带有 `(-50%)` logs 修正时 Sweep 数值被错误覆盖的问题。
- 已完成的 Crimson Isle 任务不再显示。
- 改进个人 Tree Gift 稀有生物提示，并过滤重复提示和附近其他玩家的掉落。
- 修复 Beeheemoth 声音音量调整以及 Safari 捕获 Armor Stand 被错误高亮的问题。
- AOTE/AOTV 替换音效统一使用 0–100% 音量，默认 64%，并删除音调调节。

## 删除

- 槽位/物品锁定
- Storage 覆盖
- 菜单中键点击转换
- AOTE/AOTV 音调调节

这是适用于 Minecraft 26.1.2 的纯客户端 Alpha，需要 Java 25、Fabric Loader 0.19.3+ 和 Fabric API 0.155.2+26.1.2；Mod Menu 为可选依赖。
