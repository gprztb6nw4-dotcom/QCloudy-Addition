# Beta 2.6.6 — Offline Shard Fusion Guide

QCloudy_Addition Beta 2.6.6 promotes the reviewed Alpha 2.5.6 feature set for Minecraft 26.1.2.

## Added since the 1.5.3 release baseline

- Complete offline Attribute Shard Fusion Guide for all 320 current catalog Shards.
- Search by name, ID, effect, rarity, category, family, skill, mob type, and acquisition text.
- Details, Recipes, and Uses views with ordered inputs, quantities, selectable outputs, Special Fusion yields, Chameleon behavior, and Pure Reptile information.
- Shard-specific bundled icons, documented effects/acquisition methods, semantic colours, Fusion-only labels, and reverse Fusion recipes.

## Fixed

- Search-focus lock, excessively separated recipe inputs, generic amethyst icons, incorrect Epic colour, unclear clickable text, coloured-effect spacing, and residual Wiki formatting.
- Shards with both natural and Fusion sources, including Queen Bee, now expose both kinds of acquisition.

## Removed

- Slot locking, Storage Overlay, and menu middle-click conversion.

Client-only. Requires Java 25, Fabric Loader 0.19.3+, and Fabric API 0.155.2+26.1.2. Mod Menu is optional. The guide is read-only and performs no Fusion, menu click, packet, chat, command, runtime Wiki/API request, or automation.
