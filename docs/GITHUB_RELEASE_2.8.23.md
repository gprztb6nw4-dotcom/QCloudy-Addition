# QCloudy_Addition Alpha 2.8.23 for Minecraft 26.1.2

Alpha 2.8.23 corrects island gating and removes empty or redundant settings categories.

## Fixes

- Mining Tasks & Powders now treats Crystal Hollows `Jungle` as an exact location. The Park's `Jungle Island` no longer activates the Mining HUD.
- The settings sidebar now contains only categories with at least one available feature. Empty provider-backed categories such as Dungeons disappear instead of opening a blank page.
- The subgroup inside Fishing is now **Bite Alerts**, removing the confusing Fishing → Fishing hierarchy.

## Supported file

- `QCloudy_Addition-Alpha-2.8.23+26.1.2.jar`

Fabric API remains required. Mod Menu and supported SkyBlock providers remain optional.

## Validation boundary

This remains a client-only Alpha. Automated tests and archive validation are documented in `docs/VALIDATION.md`; they do not replace an authenticated in-game check on Hypixel or every modpack and GUI Scale combination.
