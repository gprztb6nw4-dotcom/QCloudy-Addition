# QCloudy_Addition Alpha 2.8.21（Minecraft 26.1.2 / 26.2）

Alpha 2.8.21 将 Feesh 作为 QCA 的第五个可选统一设置/HUD 提供方。

## 新增

- 通过实时公开 getter/setter 成对探测 Feesh 设置能力。
- 玩家成功编辑后，通过 Feesh 自己的 `Settings.save()` 保存。
- 探测 Feesh Overlay，过滤不可见/空内容面板，正确换算锚点坐标，并编辑位置、缩放、对齐及调用原生坐标持久化。
- Feesh 会进入可视化扫描进度与按提供方分组的“兼容性缺失报告”。

## 兼容性与安全边界

- Feesh 完全可选，不是 QCA 的编译或运行依赖。
- 不使用精确 Feesh 版本白名单；兼容分支继续使用，不支持分支会被省略和报告，不会隐藏正常同级功能。
- 两个统一编辑总开关仍然相互独立且默认关闭。
- QCA 不调用 Feesh 的 API、聊天、命令、分享或玩法路径。
- Minecraft 26.1.2 与 26.2 使用独立文件，只安装与实例版本一致的文件。

自动构建可以校验代码与压缩包，但不能替代登录实服并组合安装全部提供方后的游戏内测试。
