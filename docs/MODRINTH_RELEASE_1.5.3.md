# Alpha 1.5.3 — Changes since 1.5.1

QCloudy_Addition Alpha 1.5.3 reorganizes the settings experience, improves the Hunting/Safari HUDs, fixes several parsing and empty-panel issues, and removes three inventory features that are no longer maintained.

## Highlights

- Rebuilt settings with seven clear top-level categories and collapsible subgroups.
- Added separate Galatea/Hina Chapter and Agatha's Contest tracking.
- Added optional Safari Captured Shard Stats, disabled by default and grouped by biome with rarity colors.
- Empty HUD panels now hide completely whenever they have no actual content.
- Pet HUD no longer appears in Critter Safari.
- Fixed Sweep parsing when `(-50%)` log modifiers are present.
- Completed Crimson Isle tasks are no longer displayed.
- Improved personal Tree Gift wild-creature alerts and duplicate/nearby-player filtering.
- Fixed Beeheemoth sound-volume handling and Safari Critter Armor Stand highlighting.
- Standardized AOTE/AOTV replacement volume to 0–100% with a 64% default and removed pitch control.

## Removed

- Slot/Item Locking
- Storage Overlay
- Menu middle-click conversion
- AOTE/AOTV pitch adjustment

This is a client-only Alpha for Minecraft 26.1.2. It requires Java 25, Fabric Loader 0.19.3+, and Fabric API 0.155.2+26.1.2. Mod Menu is optional.
