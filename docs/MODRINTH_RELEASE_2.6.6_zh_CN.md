# Beta 2.6.6 — 离线 Shard Fusion Guide

QCloudy_Addition Beta 2.6.6 将已经审核的 Alpha 2.5.6 功能集晋级为适用于 Minecraft 26.1.2 的 Beta 版本。

## 相比 1.5.3 Release 基线新增

- 面向当前目录全部 320 种 Shard 的完整离线 Attribute Shard Fusion Guide。
- 可按名称、ID、效果、品质、分类、家族、Skill、生物类型和获取文字搜索。
- 提供详细信息、合成来源和可合成内容，显示有序输入、数量、可选产物、Special Fusion 产量、Chameleon 规则与 Pure Reptile 信息。
- 内置 Shard 对应图标、已记录效果与获取方式、语义颜色、Fusion-only 标记及反向 Fusion 配方。

## 修复

- 修复搜索焦点锁死、配方输入间隔过远、通用紫水晶图标、Epic 颜色错误、可点击文字不清晰、彩色效果空格丢失与 Wiki 格式残留。
- Queen Bee 等同时拥有自然来源与 Fusion 来源的 Shard 会显示两类获取方式。

## 删除

- 槽位锁定、Storage 覆盖与菜单中键转换。

本模组为纯客户端；需要 Java 25、Fabric Loader 0.19.3+ 与 Fabric API 0.155.2+26.1.2，Mod Menu 为可选依赖。Guide 只读，不执行 Fusion、菜单点击、数据包、聊天、命令、运行时 Wiki/API 请求或自动操作。
