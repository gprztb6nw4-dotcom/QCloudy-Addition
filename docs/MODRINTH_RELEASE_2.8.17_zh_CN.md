# Beta 2.8.17——外部模组更新兼容

- 删除提供方精确版本白名单，改为探测实时配置与保存能力。
- 加入分别管理第三方设置与第三方 HUD 编辑的独立总开关，两者均默认关闭。
- SkyHanni、Skyblocker、Firmament、BabyZombieAddons 正常更新后，结构仍兼容的已知设置和 HUD 坐标可以继续编辑。
- 未知或已经改变的分支会单独省略，不再让整个提供方消失。
- 启用对应总开关后，每次打开 QCA 设置时重新探测提供方能力。
- 删除 `/aca` 与 `/ca`；`/qca`、`/qc` 仍是本地设置命令。
- QCA 对 Minecraft 26.1.2 与 26.2 仍可独立、纯客户端运行。
