# QCloudy_Addition Alpha 2.8.20（Minecraft 26.1.2 / 26.2）

Alpha 2.8.20 让可选的统一 SkyBlock 模组编辑器变得可预测、可视化，并且保持设置/HUD 相互独立。

## 新增

- 开启“统一设置编辑”或“统一 HUD 编辑”后会直接打开实时能力扫描页面。
- 页面显示进度、正在读取的已安装提供方、当前阶段/内容、最近活动，以及只属于当前编辑器的结果数量。
- 两个页面都加入手动 **Refresh**。
- 对原生路径和已验证规则后仍未分类的提供方功能，使用小型、确定性的离线分类器。

## 改进

- 设置与 HUD 探测共用一份通过校验的会话快照，但开关与显示数量完全独立。
- 只显示已安装且成功提供可读能力的模组，不提示未安装模组。
- Refresh 期间继续使用上一份有效快照，新结果完成并校验后才替换。
- 普通打开设置菜单不再扫描；两个统一编辑开关都关闭时会取消待处理工作并卸载快照。

## 安全与兼容边界

- 提供方版本不是精确白名单。更新后仍兼容的已识别分支可以继续工作，变化分支会逐项安全关闭。
- 扫描和分类完全在本地只读完成，不使用云端 AI、不下载模型，也不发送 HTTP、服务器查询、数据包、命令、聊天、遥测或自动输入，不直接修改配置文件。
- QCA 仍可独立运行；SkyHanni、Skyblocker、Firmament、BabyZombieAddons 都是可选模组。

请根据 Minecraft 版本选择对应 JAR，不要把 Sources JAR 当作可运行模组安装。
