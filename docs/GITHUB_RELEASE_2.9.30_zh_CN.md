# QCloudy_Addition Alpha 2.9.30（Minecraft 26.1.2）

Alpha 2.9.30 修复重新放置 SOS/Flare 后仍按旧时间提前提醒的问题。

## 修复

- 在 Warning、Alert 或 SOS Flare 仍生效时重新放置，会从本次识别到的重新使用时刻计算完整三分钟；覆盖旧 Flare 没有重复首次确认信号时也会重置。
- 旧 Flare 的到期时间会失效，不会在新 Flare 仍生效时弹出提醒。
- 放置追踪现在同时读取普通物品使用和对方块使用物品两条交互路径。
- 如果第二次使用回调漏失，只有精确成功放置音效与本地玩家仍手持已知 Flare 同时成立时才会恢复确认。
- 增加同种 SOS 替换、使用回调漏失恢复和手持无关物品的回归测试。

## 兼容与安全

- QCloudy_Addition 仍是可独立运行的纯客户端 Fabric 模组。
- 提醒不使用距离、增益范围或实体卸载，也不会发送指令、数据包或自动交互。
- Power Orb 聊天匹配和现有提醒设置没有改变。

## 下载

可运行模组：

- `QCloudy_Addition-Alpha-2.9.30+26.1.2.jar`

开发者源码：

- `QCloudy_Addition-Alpha-2.9.30+26.1.2-sources.jar`

只安装可运行 JAR，不要把 `-sources.jar` 当作模组安装。

Minecraft 26.1.2 已通过完整自动测试，0 失败，并完成元数据和归档校验。仍需在 Hypixel 实服验证替换场景：在旧三分钟结束前重新放置 SOS，确认旧时间点不提醒，并且新时间点只提醒一次。
