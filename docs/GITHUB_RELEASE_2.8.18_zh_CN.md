# QCloudy_Addition Alpha 2.8.18（Minecraft 26.1.2 / 26.2）

Alpha 2.8.18 新增一个清晰、只读的兼容性报告，用来查看已安装 SkyBlock 模组中哪些已识别设置或 HUD 仍无法由 QCA 统一管理。

## 新增

- 在 **通用 → 兼容模组** 中新增 **兼容性缺失报告**。
- 这张特殊卡片没有开关或启用条，鼠标左键和右键都能打开。
- 结果按照 SkyHanni、Skyblocker、Firmament、BabyZombieAddons 分组。
- 每个确定的缺失项目会标记 `[设置]`、`[HUD 编辑]` 或两者；正常支持的功能不会显示。

## 兼容逻辑

- 即使两个统一编辑总开关关闭，玩家主动打开报告时仍会执行一次新的只读能力检查。
- 已识别的提供方配置根为空或无法读取时，会显示提供方级缺失，不会错误显示为“全部支持”。
- 已识别但无法安全写入的复杂颜色、组合按键或位置结构可以进入报告，同时不会被开放到普通编辑器。
- 对完全未知的未来结构不会随意编造功能名称。

## 安全边界

报告不会修改提供方设置或文件，也不发送数据包、命令、聊天、HTTP 请求或遥测。QCA 仍可独立运行，并保持纯客户端。

请下载与 Minecraft 版本完全对应的可运行 JAR，不要把 Sources JAR 当作模组安装。
