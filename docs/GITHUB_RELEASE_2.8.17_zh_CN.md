# QCloudy_Addition Beta 2.8.17（Minecraft 26.1.2 / 26.2）

这个 Beta 改进了统一设置与 HUD 编辑器：以后 SkyHanni、Skyblocker、Firmament 或 BabyZombieAddons 正常更新版本时，不会只因版本号不在白名单中就让整个集成消失。

## 变化

- 删除精确版本白名单，改为探测模组当前实际提供的配置与保存能力。
- 在“通用”中加入相互独立的“统一设置编辑”和“统一 HUD 编辑”总开关；两者都默认关闭，不影响 QCA 自身功能。
- 启用对应总开关后，每次打开 QCA 设置时重新检查已安装提供方的配置根对象和原生保存/update 接口。
- 提供方更新后，只要原有功能和 HUD 坐标结构仍兼容，就继续显示并允许安全编辑。
- 未知、不可访问、只读、不支持或已经改变的分支会单独省略，不再连带隐藏整个模组。
- 支持识别 `enabledCommissions` 搭配 `commissionsX`、`commissionsY`、`commissionsScale` 这类常见前缀结构，不依赖每个版本的固定字段清单。
- 删除本地设置别名 `/aca` 与 `/ca`。请使用 `/qca`、`/qc`、默认 `O` 键或 Mod Menu。

## 兼容边界

这是防御性的尽力兼容，不代表 QCA 能自动理解未来新增的所有设置。如果提供方删除了已识别的配置根对象或原生保存/update 契约，只会隐藏该提供方适配器，直到 QCA 支持新结构。QCA 不会直接修改其他模组的配置文件；即使四个可选提供方全部未安装，QCA 自身仍可独立使用。

请安装与 Minecraft 版本完全对应的可运行 JAR。`-sources.jar` 是源码附件，不能作为模组运行。
